Install Bigorna

This page installs Bigorna on an M-VAVE FM-1 connected to this computer, over USB MIDI. It works in a desktop Chrome, Edge or Opera. It talks to the FM-1 directly: nothing is uploaded anywhere.

Read this first. Bigorna is an unofficial firmware, not made, endorsed or supported by M-VAVE or Elektron. Installing it replaces the FM-1's firmware and may void any warranty that applies to your device. An interrupted update can leave the FM-1 unable to start until it is recovered. Saving Bigorna sessions overwrites any projects another firmware left on the device. The software comes with no warranty of any kind; you install it entirely at your own risk. Full disclaimer.

Before you start

  1. Use a USB cable that carries data (some carry power only), plugged straight into the computer.
  2. Switch the FM-1 on, and close any other program using MIDI (a DAW, M-VAVE's app).
  3. When the browser asks to let this page control MIDI devices, allow it: the update is sent as MIDI system-exclusive messages.

After installing

Switch the FM-1 off and on once. Bigorna renders on both of the FM-1's processor cores; if the second core was ever stopped (after a fault on it), it stays stopped until the power is switched off, and the screen says 1 CORE at start-up.

If something goes wrong

Stopped part-way? Reload this page and install again: an FM-1 left in update mode is found and the write is finished. If the FM-1 starts but does not answer over USB, put it in the chip's own update mode — hold OCT− and OCT+ for 5 seconds while it runs — and restore a firmware with Melodee's recovery tool (macOS, Linux, Windows) or FM-1-transporter.

Prefer the command line? Build and install from source.

The installer (js/fm1ota.js) is a port of Felucca's installer, GPL-3.0; the firmware it installs is GPL-3.0, its source on GitHub.
