Back up sessions

This page copies the sessions stored on an FM-1 running Bigorna — each with its patterns and loops — and the GLOBAL SETUP settings (MIDI, MIDI LEARN) to a file on this computer, and puts them back from that file. Use it before you install another firmware (it may erase or overwrite them): when you reinstall Bigorna, restore the file here. It works in a desktop Chrome, Edge or Opera, over USB MIDI, and needs Bigorna build 55 or later on the FM-1. Nothing is uploaded anywhere: the file stays on this computer.

Not connected

Connect the FM-1 with a USB data cable, switch it on, then find it.

On the FM-1
In the file
no file opened

Restore

Open a backup file, then write it to the FM-1. Every session in the file replaces the one in the same slot on the FM-1, with its patterns and loops; GLOBAL SETUP is replaced if the file holds it. The other sessions on the FM-1 are kept.

Notes

  • Close any other program using MIDI (a DAW, M-VAVE's app), and allow MIDI access when the browser asks: the sessions travel as MIDI system-exclusive messages.
  • The FM-1 keeps playing while this page works, but writing to its flash silences the audio for a moment each time.
  • Each part is copied whole and checked before it is written: one that does not arrive intact is not written. A session's loops are written before the session, so a restore cut off leaves that session as it was.
  • The session playing on the FM-1 is not changed by a restore: load it again (SAVE, then LOAD) to hear what was restored. Save it first if it has changes you want to keep.

The page (js/backup.js) and the part of the firmware that answers it (firmware/src/backup.c) are GPL-3.0, on GitHub. They follow Tonitor's backup page.
